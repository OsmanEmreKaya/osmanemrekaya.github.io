# osmanemrekaya.github.io

GitHub Pages kullanıcı sitesi. Tek işi `app-ads.txt`'yi alan adının kökünden
servis etmek: <https://osmanemrekaya.github.io/app-ads.txt>

AdMob ve diğer reklam ağlarının tarayıcıları app-ads.txt'yi yalnızca kökten
okur, alt dizinden okumaz. Stretch Escape'in sitesi
<https://osmanemrekaya.github.io/stretchescapewebsite/> altında yayınlandığı
için dosya oradaki kopyasıyla bulunamıyordu; bu depo o boşluğu kapatıyor.

Dosya iki yerde duruyor (burada ve `stretchescapewebsite` deposunda). AdMob
yayıncı kimliği değişirse **ikisini birlikte** güncelle.

`.nojekyll` duruyor çünkü Jekyll'e ihtiyaç yok.
